# Security Policy

This project performs bounded, read-only audits of public websites. Its current network limitations and safe-use rules are documented in [docs/SECURITY.md](docs/SECURITY.md); read that document before reporting or changing network behavior.

Do not publicly disclose exploitable details, target URLs containing credentials/tokens, or unredacted audit reports.

Use GitHub's Security tab and **Report a vulnerability** flow when private vulnerability reporting is enabled. If unavailable, contact the repository owner privately through their GitHub profile and request a secure disclosure route. Do not publish details while arranging contact.

Include the affected version/commit, exact URL-safety or request path, minimal reproduction against a controlled target, actual impact, and redacted logs. Never test targets without authorization.
